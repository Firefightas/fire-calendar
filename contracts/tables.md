# Tabular contracts (Parquet)

Produced in `data/processed/<region_id>/`, too big for JSON. Column names and types are exact. Mocks with the same columns live in `contracts/mocks/<region_id>/*.sample.csv` (generated by `contracts/mocks/generate_mocks.py`).

## `points.parquet`: one row per detection (after filtering). Producer: P2

| Column | Type | Notes |
|---|---|---|
| `date` | date | acquisition date (UTC) |
| `time` | string `HHMM` | acquisition time (UTC) |
| `lat` | float64 | pixel center |
| `lon` | float64 | pixel center |
| `h3` | string | H3 res-7 cell of (lat, lon) |
| `sensor` | enum | `modis`, `viirs` |
| `satellite` | enum | `terra`, `aqua`, `snpp`, `noaa20`, `noaa21` |
| `confidence_class` | enum | `low`, `nominal`, `high` (MODIS: <30 low, 30–79 nominal, ≥80 high) |
| `frp` | float64 | fire radiative power, MW |
| `daynight` | enum | `D`, `N` |
| `type` | int8 or null | MODIS SP type (0 vegetation fire); null when the source has no type |
| `is_nrt` | bool | true for near-real-time rows |

Filtering already applied: `type` in (0, null), `confidence_class != low`, inside the region bbox.

## `hex_day.parquet`: one row per (hex, day, satellite). Producer: P2

| Column | Type | Notes |
|---|---|---|
| `h3` | string | H3 res-7 cell |
| `date` | date | |
| `sensor` | enum | `modis`, `viirs` |
| `satellite` | enum | `terra`, `aqua`, `snpp`, `noaa20`, `noaa21` |
| `n_points` | int32 | detections in that hex that day |
| `frp_sum` | float64 | MW |

Counting cell-days (TEAM_PLAN §2.1):
- per satellite: `COUNT(*)` grouped by satellite and month;
- MODIS Terra+Aqua combined: `COUNT(DISTINCT (h3, date))` where `sensor = 'modis'` (a hex seen by both Terra and Aqua on the same day counts once).

## `hex_fire_history.parquet`: one row per hex. Producer: P3 → consumer: P2 (sandbox grid)

| Column | Type | Notes |
|---|---|---|
| `h3` | string | H3 res-7 cell |
| `burn_count` | float64 | harmonized fire cell-days, whole record |
| `years_since_last_fire` | float64 or null | years from last detection to the latest data date; null if never |
